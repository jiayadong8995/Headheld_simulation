# 双滚刷手持式洗地机器人：一维助力控制仿真任务书（交付给 Herens）

**版本**：V1.0（算法概念验证与参数整定）  
**研究对象**：左右对称系统中的**单侧半车、单驱动电机**，只模拟前后方向一维平动。  
**目标**：比较现有电流加速度助力算法与基于速度/加速度反馈的虚拟阻抗助力算法，进行鲁棒性和参数整定研究，交付可复现实验代码、曲线、参数推荐和风险结论。

> **不要把它扩展成双侧差速/转向控制，不建滚刷旋转动力学，不引入位置刚度项。** 前后滚刷对平动的影响以合成外力/阻力表征。不要假定已经测得用户手推力，也不要把仿真真值送入实机控制器。

## 1. 系统定义与控制目标

### 1.1 坐标系与符号

- 沿机器人前进方向定义 `+x`，向后拉/推为负；使用**带符号**的力和速度，支持正反两个方向。
- `x [m]`：半车在地面前后方向的位置；`v [m/s]`：速度；`a [m/s²]`：加速度。
- `m [kg]`：单侧等效平动质量（若已包含传动旋转惯量等效质量，不要再次叠加）。
- `F_h [N]`：作用到此单侧模型的用户手柄外力；左右对称理想情况下 `F_h_total=2*F_h`。
- `F_m [N]`：单侧驱动电机经传动/驱动轮转化的实际地面切向驱动力。
- `F_br [N]`：前后滚刷产生的合成**有符号**平动作用力，可助推也可阻碍。
- `F_res [N]`：接地、粘滞、滚动等方向相关的阻力。
- `D=F_res-F_br [N]`：全部外部净阻力；**不保证恒正**，不应简化为固定的常数。
- `F_cmd [N]`：上层助力控制器给出的驱动力指令；`F_m` 是实际执行结果（两者不一定相等）。

基础真实模型：

```math
\dot x=v,\qquad m\dot v=F_h+F_m-D(v,t).
```

> 注意：摩擦有方向，不能写成 `m*a=F_h+F_m-F_r` 且始终假定 `F_r>0`，否则反向测试的模型会错。

### 1.2 核心目标：改变用户感受到的惯量与阻尼

目标虚拟阻抗（自由运动，不加刚度项）：

```math
F_h=M_d\dot v+B_d v,
```

其中 `M_d>0 [kg]` 为目标等效惯量，`B_d>0 [N*s/m]` 为目标等效阻尼。对理想对象，控制律应为：

```math
F_{cmd}=(m-M_d)\hat a-B_d\hat v+\hat D.
```

统一写成可调控制器：

```math
F_{cmd}=K_a\hat a-B_d\hat v+\alpha_D\hat D,
\quad K_a=\hat m-M_d.
```

仅当 `\hat m=m`、`\hat D=D`、`\alpha_D=1`、传感器无误差且执行器可瞬时准确产生指令时，才有 `F_h=M_d*a+B_d*v`。实际残差满足近似：

```math
F_h=(m-K_a)a+B_dv+[D-\alpha_D\hat D]+[F_{cmd}-F_m]+\text{测量误差项}.
```

**务必检查 `m-K_a>0` 在质量不确定性下成立**。`K_a*a` 是正加速度反馈，等效惯量越小，控制越激进；电机延迟和噪声可使其振荡或接近失稳，不允许直接把 `M_d` 调到接近零。

### 1.3 实验目标（不是提前保证的结论）

1. 用更小的用户推拉力完成同样的行程/跟踪任务。
2. 启动、持续移动、换向、松手后都自然，没有明显主动窜动、反向冲击和抖动。
3. 地面干湿、刷头更换、摩擦力变化后，既保持稳定，又尽量保持一致手感。
4. 指令满足实际电机输出和通信能力；不以高峰值扭矩掩盖算法问题。
5. 确认速度反馈、加速度反馈、阻力补偿各自的效果与代价。

## 2. 被控对象（Plant）

### 2.1 最小连续模型（先确保可验证）

状态：`z=[x, v, F_m]^T`。真实对象：

```math
\dot x=v,
\quad \dot v=(F_h+F_m-D)/m,
\quad \tau_F \dot F_m=\operatorname{sat}(F_{cmd,delayed},-F_{max},F_{max})-F_m.
```

`tau_F` 为**电流环+驱动机械链路**的等效力响应时间常数；先设可配置，**不是规格书已知参数**。为避免加速度反馈的虚假代数环，控制器只能使用采样可获得的**过去/当前已观测信号**，不可在同一时间步用尚未发生的真实 `a` 计算 `F_cmd`。

分层实现：`dt_plant=0.001 s`（积分）、`T_control=0.01 s`（初始 100 Hz），传感器采样周期和 UART 往返延迟独立可配；控制指令零阶保持。使用固定随机种子；积分器可用 RK4 或 `solve_ivp`，遇到粘滑切换时可用确定性离散法，确保稳定复现。

### 2.2 阻力/刷头模型：平滑版本 + 粘滑版本

**平滑模型（方便先推导和调参）**：

```math
F_{res}(v,t)=b(t)v+
\big[F_c(t)+(F_s(t)-F_c(t))e^{-(|v|/v_s)^2}\big]\tanh(v/v_\epsilon),
\quad D(v,t)=F_{res}(v,t)-F_{br}(t).
```

- `b`：粘滞阻尼 [N*s/m]。
- `F_c`：动摩擦力幅值 [N]。
- `F_s`：静摩擦最大幅值 [N]，通常 `F_s>=F_c`。
- `v_s`：Stribeck 速度尺度；`v_epsilon`：符号平滑尺度。
- `F_br(t)=F_dc(t)+A_br*sin(2*pi*f_br*t+phi)+colored_noise(t)`；频率和幅值只是初始假设，待滚刷试验辨识。

**粘滑版本（一定要独立测试）**：当 `|v|` 足够小、且驱动合力 `|F_h+F_m+F_br|<=F_s` 时，置 `v=0, a=0`；合力大于 `F_s` 后按外力方向破静摩擦进入运动状态。运动时采用连续摩擦函数。阈值附近须防止数值频繁切换（滞回区和零速锁定）。

至少预留三个工况/刷头配置：`dry / wet / new_brush`。在运行途中允许瞬时或连续切换；同时支持双滚刷合力改变方向、低频偏置和周期扰动。**控制器只能拿到名义阻力模型，不能直接读取真实 `D`。**

### 2.3 电机、执行与力转换

先运行**纯力接口** `F_cmd -> F_m`，以验证控制规律；再增加真实的转矩/电流/速度约束：

```math
\tau_w=\eta G\tau_m,\quad F_m=\tau_w/r,
\quad \tau_m\approx K_t i_q \; (\text{线性近似，待标定}).
```

`r`：有效驱动半径，`G`：传动比，`eta`：效率；若是直驱，先取 `G=1`，但 `r/eta/K_t` 均应由装配和测试确定。

**此前提供的 M0603B_235 A0 电机规格书中，可直接引用的事实**：

| 项目 | 规格书参数 | 仿真解释 |
|---|---:|---|
| 额定输出转矩 | 0.25 N·m | 可暂用于连续力上限的保守标尺 |
| 堵转转矩 | 0.85 N·m | **不是**允许持续输出的峰值额定值 |
| 额定转速 | 98 rpm | 对应额定工况，不是绝对速度上限 |
| 空载转速 | 210±15 rpm | 仅作为空载速度标尺 |
| 额定电流 | 0.5 A | 不确定是否等价于通讯中的 `i_q`，不可直接推 `K_t` |
| 堵转电流 | ≤3 A | 不是持续工作电流许可 |
| 额定电压 / 工作范围 | 14.4 V / 12–28 V | 用于运行包络设置 |
| 编码器分辨率 | 12 bit | 可构建编码器测量模型，实际速度反馈分辨率另测 |
| 控制方式 | 电流环/速度环等 | 本方案优先评估电流/力指令路径 |
| 通讯 | UART 115200，10 字节命令与回复，一问一答 | 实测确认 100 Hz 闭环调度是否可达 |

协议的电流指令区间 `-32767..32767 -> -8..8 A` 是**指令编码比例，不是允许连续输出 8 A**；同时有母线过流阈值 2.8 A（持续 >5 s 停机）等保护。协议可回复 `i_q`，也可回复母线电流，但两者不能混为一谈。不要用 `0.25/0.5=0.5 N*m/A` 直接认定真实 `K_t`。

建议：第一阶段基于 `|tau_w|<=0.25 N*m` 的**示例保守连续力包络**验证（假设该规格的 0.25 N·m 是可持续额定点；仍须结合温度和工况复核）。只有掌握厂家允许的瞬态时长和实际热限制后，才启用短时峰值转矩曲线；不可把 0.85 N·m 堵转转矩当作任意时刻可调用的峰值。

执行器必须有：`torque_sat`、可配置的速度-扭矩能力曲线（无数据时不猜测，先用矩形保守包络）、`force_slew_limit`、一阶响应、指令延迟、丢帧、失能/急停。

## 3. 传感器与状态估计器（必须与物理真值隔离）

真实状态只供 plant/离线评价。实机控制器入口必须是带噪声的测量：

```math
a_{imu}=a+g\sin\theta+b_a+n_a+e_{vib},
\qquad v_{enc}=(1-s)v+n_v+e_q.
```

`theta` 为 IMU 轴向与水平的偏角，`b_a` 为偏置，`e_vib` 为滚刷振动；`s` 为驱动轮打滑因子，`e_q` 为编码器测速量化/离散误差。模型只用一维平动；倾角在这里仅是重力投影造成的**测量误差**，并非在模拟俯仰自由度。

**不要把 IMU 加速度直接积分当成长期可靠的速度真值**。初版使用一维互补融合：

```math
v^-_{k}=\hat v_{k-1}+T_s( a_{imu,k}-\hat b_a ),
\quad \hat v_k=(1-\lambda)v^-_k+\lambda v_{enc,k}.
```

加速度估计单独通过一阶低通/带限滤波得 `a_hat`（防止加速度正反馈放大高频噪声）。`lambda`、加速度滤波截止频率、时间戳对齐、采样间隔、失帧策略应配置并做参数扫描。

可选第二阶段：使用简单 Kalman 状态估计器对 `v, a_bias` 估计，与互补滤波对比；**不要在第一阶段引入复杂 EKF 作为前置条件**。

### 3.1 关于用户力的估计：作为独立研究项

动力学逆推的候选估计：

```math
\hat F_h=\hat m\hat a-\hat F_m+\hat D.
```

但**当 `F_h` 与 `D` 同时未知时，仅凭加速度、速度、电流不足以唯一分离两者**：只能先辨识或估计净外力 `F_h-D`。不允许以仿真真值 `D` 计算 `F_h_hat` 后宣称传感器已能精确估计用户意图。

主方案 `C2/C3` 不依赖 `F_h_hat` 才能工作。`F_h_hat` 用于离线误差分析；若加入导纳方案，须单独说明额外先验/力传感器需求。未来真实设备辨识阶段建议使用临时装配的手柄拉压力传感器记录 `F_h` 真值，但仿真控制器不得偷用该值。

## 4. 控制算法组（统一物理对象、限制和测试输入）

所有方案共享**相同的执行器饱和、控制周期、滤波、通信延迟和相同的随机种子**；所有算法可调参数放入 YAML，禁止硬编码在控制器函数中。

### C0：完全无电机助力（物理基准）

```math
F_{cmd}=0.
```

### C1：现有方案 `i = i_base + k*a`（必须提供可复现实例）

```math
i_{cmd}=i_{base}(q,\operatorname{sgn}\hat v)+k_a(q)\hat a,
\quad q\in\{\text{启动、前进、后退、停止}\}.
```

此处 `k_a` 单位 A*s²/m，勿与新控制器的 `K_a` [kg] 混用。先将其映射到力 `F_cmd`；若 `K_F=F/i_q` 尚未标定，则**以可配置的力增益 `F_base + K_{a,old}*a_hat` 实现数学等价版本**，清楚标记为模型抽象。

实现状态机、`i_base`、分状态增益、现有削减/限幅和低通滤波；若缺少现行固件的准确系数，建立显式占位默认值并在结果中说明，不得称为「现有实机效果的复现」。

### C2：只用加速度+速度反馈的基础阻抗控制

```math
F_{cmd}=K_a\hat a-B_d\hat v,
\quad K_a=\hat m-M_d.
```

用于隔离「增加速度反馈」的净贡献。所有比较均要包括此组。

### C3：阻抗控制 + 名义阻力补偿（本次主要候选）

```math
F_{cmd}=K_a\hat a-B_d\hat v+\alpha_D\hat D(\hat v, \text{estimated mode}),
\quad 0\le\alpha_D\le 1.
```

`D_hat` 只用独立辨识到的名义阻力参数、可获得的滚刷模式指令和已滤波的速度；不得用真实摩擦参数随工况自动切换（除非该工况标签在真实系统确实可观测）。

在零速附近为阻力补偿引入衰减/死区与软切换，避免 `F_h=0` 时刷头方向力或噪声诱发主动起步。`alpha_D=1` 不意味着最佳：模型错误越大，补偿越容易误推。

### C4：C3 的两项「上限对照」，不作为可部署算法

- `C4a = perfect_state`：用真实 `a,v`，但仍使用**名义**阻力估计，用于定量观察传感器误差的损失。
- `C4b = oracle_D`：用真实 `D`，只在离线场景作为最佳情况上限，严禁将其纳入实机参数排名。

### C5：导纳对照（可选，非本轮主线）

使用可被实际获得的 `F_h_hat`：

```math
M_d\dot v_{ref}+B_dv_{ref}=\hat F_h,
\quad F_{cmd}=K_p(v_{ref}-\hat v)+K_i\int(v_{ref}-\hat v)dt+F_{ff}.
```

加入抗积分饱和、估计力滤波、物理限幅。若只用真实 `F_h` 作输入，只能标注为 `C5_oracle_force` 理想基准，不可直接证明导纳比阻抗更可行。**C5 可在 C0–C3 完成后再跑。**

### 4.1 四阶段状态处理（统一安全外壳）

- `REST`：持续静止，指令逐渐归零；无可靠用户意图时不得主动产生恒定推力。
- `START`：观察到真实运动启动迹象后软启动；低速时避免大静摩擦前馈产生窜动。
- `MOVE`：速度/加速度反馈助力；正反向均允许，不用正向特判代替一般方程。
- `STOP/REVERSE`：松手减速或用户反拉换向；加速度增益/摩擦补偿可减小，阻尼保留，指令连续过渡。

状态判断只能用 `v_hat, a_hat, 可用的其他实时量`（若引入力估计必须注明误差），不能读取真实用户力。状态条件使用速度和时间双滞回，避免频繁抖动。至少配置死区、最大力、最大力变化率、超时归零、保护失能和重启初始化状态。

## 5. 两类人手输入模型：不要只看同一个推力波形

### 5.1 力给定试验：同一 `F_h(t)` 下比较响应

目的：看在**相同手推力**下，哪一组移动更灵敏、是否振荡、能否按目标阻抗运动。示例（均为**单侧力**）：

- `push_release`：0–0.5s 线性从 0 增至 +5 N，0.5–2.5s 保持，2.5–3s 回落至 0，记录松手后 3–6s 行为。
- `pull_release`：全部取相反符号 -5 N。
- `weak_push`：3 N 附近小推力测试；注意可能受静摩擦影响而无法起步，不能据此判算法失效。
- `rapid_reverse`：+5 N 保持 2 s，200 ms 过渡至 -5 N，继续 2 s。
- `oscillatory`：正负 4 N、0.5–2 Hz 的往返推拉，以观察相位滞后与过冲。
- `no_human_force`：F_h=0，初始 `v=0` 和初始 `v≠0` 分开做，验证「不自启动」与「松手后安全停下」。

**说明**：在给定推力相同的情况下，位移变大、速度变高，并不自动等于更省力；还需要下一类试验。

### 5.2 给定行程的人机耦合试验：同一任务下比较人的付出

构建受限、带反应延迟的「虚拟用户」模型：

```math
F_{h,des}=K_{p,h}(x_{ref}-x)+K_{d,h}(v_{ref}-v),
\quad \tau_h\dot F_h=\operatorname{sat}(F_{h,des},\pm F_{h,max})-F_h.
```

再叠加可配置的人手反应延迟与最大用力变化率。**虚拟用户参数固定**（比较全部控制器时不得为某一控制器特别调整），且避免设置得过分强硬；对 `Kp_h/Kd_h/tau_h` 做三组保守变化，防止结论仅由一种「虚拟人」决定。

至少三种任务：

1. 从静止推动 `+0.8 m` 后停止并保持。
2. 推 `+0.8 m`，再回拉 `-0.8 m`，然后停止。
3. 行程中 40%–60% 阶段突然由 dry 切 wet，或替换刷头，检测额外需要的用户力。

在这组试验比较 `RMS(F_h)`、峰值手力、人的正机械功、完成时间、位置精度。**主要助力效果应在同一任务条件下定义，而不应单凭固定手力下的速度变化。**

## 6. 参数、运行设置及建议默认值（全部是示例占位，非实机实测）

建议从同目录的 `config_initial.yaml` 读取。首次运行需在报告中明确打印：哪些参数来自规格书、哪些来自用户当前模型、哪些只是仿真假设。

示例初值：

| 类别 | 参数 | 首次运行参考值 | 扫描/检验方向 |
|---|---|---:|---|
| 运动质量 | `m` | 4.0 kg/单侧 | ±25%，待称重/辨识 |
| 驱动半径 | `r` | 0.04 m | 按实物尺寸修正 |
| 传动比 | `G` | 1 | 以实际传动为准 |
| 名义摩擦 | `F_c_dry` | 1.5 N | 与含水量/刷头相关 |
| 静摩擦 | `F_s_dry` | 2.5 N | 开始移动阈值 |
| 湿地动摩擦 | `F_c_wet` | 3.5 N | 工况阶跃 |
| 湿地静摩擦 | `F_s_wet` | 5.0 N | 工况阶跃 |
| 粘滞 | `b` | 2.0 N*s/m | 扫描 ±50% |
| 刷头合成偏置 | `F_br_dc` | 0 N | ±1 N 可正可负 |
| 刷头脉动 | `A_br` | 0.5 N | 0–1.5 N；频率 2–8 Hz |
| 力执行环时间常数 | `tau_F` | 0.04 s | 0.02 / 0.04 / 0.08 s |
| 控制周期 | `T_control` | 0.01 s | 0.005/0.01/0.02 s；最终要满足实机带宽 |
| 对象积分周期 | `dt_plant` | 0.001 s | 收敛检查时减半 |
| IMU 加速度噪声 std | `sigma_a` | 0.08 m/s² | 0.03–0.20 m/s² |
| IMU 偏置 | `b_a` | 0.03 m/s² | ±0.1 m/s² 漂移 |
| 编码器速度噪声 std | `sigma_v` | 0.01 m/s | 扫描；考虑量化 |
| 轮速偏差/打滑 | `s` | 0 | 0–15% |
| 合计反馈延迟 | `delay` | 0.02 s | 0–0.06 s |
| 加速度滤波截止 | `f_a` | 10 Hz | 5/10/15 Hz，须低于相应 Nyquist 频率 |
| 惯量补偿比 | `K_a/m_nom` | 0.35 | 0/0.2/0.35/0.5/0.6（均需先做安全筛选） |
| 目标阻尼 | `B_d` | 4 N*s/m | 2/4/8 N*s/m |
| 阻力补偿比例 | `alpha_D` | 0.5 | 0/0.5/0.8/1.0 |

例如仅为了直观展示，当 `r=0.04 m`、`G=eta=1` 时，0.25 N·m 相当于 `6.25 N` 的驱动力标尺。这**不是整机实际最大推力测量结果**；若 r、传动或轮地条件变化，这个值必须重新计算。

### 6.1 搜索顺序（防止全组合爆炸）

1. **解析验证**：理想线性对象，无噪声/延迟/饱和，固定 `K_a/m` 和 `B_d` 验证闭环公式。
2. **单因素扫描**：分别扫描 `K_a/m`、`B_d`、`alpha_D`，其余保持一致。先识别发散或振荡边界。
3. **两因素网格**：扫描 `K_a/m × B_d`，画热图，包括「减小手力」「松手停止」「加速度抖动」三个相互制约指标。
4. **鲁棒性 Monte Carlo**：至少 200–300 组独立随机工况（推荐 300 组），每组使用相同随机样本评估所有候选参数。
5. **帕累托筛选**：从“使用者负担”“手感平顺”“过冲/停稳”“电机负担”“最差工况安全”中挑 3–5 组候选，而非靠单一目标函数挑最大增益。

安全筛选先于性能排名：`K_a < m_min`（保留工程裕度）、真实扭矩/电流/通信限制满足、无自启动/持续振荡。

### 6.2 Monte Carlo 随机工况的初始分布（示例，全部标为 ASSUMED）

每个样本包含**同一组随机物理参数/噪声序列**，重复跑所有控制器以保证配对比较；勿为 C3 换一组更轻松的干湿/噪声环境：

- `m_actual/m_nominal ~ Uniform(0.75,1.25)`；`b_actual/b_nominal ~ Uniform(0.5,1.5)`。
- `F_c_actual/F_c_nominal ~ Uniform(0.6,1.7)`；`F_s_actual/F_s_nominal ~ Uniform(0.7,1.5)`，并强制 `F_s>=F_c`。
- `F_br_bias ~ Uniform(-1.0,1.0) N`；刷头纹波幅值 `~ Uniform(0,1.5) N`、纹波频率 `~ Uniform(2,8) Hz`。
- `tau_F ~ Uniform(0.02,0.08) s`；总通信/处理延迟 `~ Uniform(0,0.06) s`；失帧率从 `{0,0.01,0.05}` 中采样。
- `imu_bias ~ Uniform(-0.1,+0.1) m/s²`；IMU 倾斜投影的等效角偏差 `~ Uniform(-2,+2)°`；轮速打滑比 `~ Uniform(0,0.15)`。
- 人手响应时间 `tau_h ~ Uniform(0.10,0.25) s`，并独立检查固定人手参数的主比较（防止人手分布成为调参捷径）。

前述值只是用于暴露不稳定区的探索分布；**不等于真实设备的公差统计**。若参数相关性明显（如湿地 `F_s/F_c` 相关），要保留物理关联，不能制造 `F_s<F_c` 的非法样本。提交 Monte Carlo 种子、样本清单、失效样本细节和每组控制器的配对性能差。

### 6.3 单次仿真的采样顺序（防止物理真值泄漏与代数环）

```python
for k in range(N_control_steps):
    # 只采集截至 t_k 已经产生的历史值；包含采样/通信延迟
    meas = sensors.read_delayed_history(plant_history, timestamp=t_k)

        logger.append_truth_and_measurements(...)  # 真值只记录给离线评价器
    previous_motor_feedback = motor_feedback_from_sensor_pipeline(...)
# 绘图/评价阶段才可读取全部真值 F_h, D, a, v
```

## 8. 评价指标与计算口径

**控制效果**：

- `v_ref`：以该次试验的**真实测试人力** `F_h` 积分理想目标方程 `M_d*dv_ref/dt+B_d*v_ref=F_h` 得到；仅用于离线对照，控制器禁止读取。
- `RMSE_v=RMSE(v-v_ref)`：衡量给定手力下的目标阻抗拟合程度。
- `Z_residual_RMSE=RMSE(F_h-M_d*a-B_d*v)`：只在规定的运动时段、且记录阻力残差和执行饱和时解释；静摩擦状态不可直接作为失败证据。
- `M_eff_fit/B_eff_fit`：对 `F_h≈M_eff*a+B_eff*v` 进行最小二乘辨识；报告拟合误差/置信区间，注明工况下未补偿阻力可能使拟合有偏。

**手柄交互**（主要在人机耦合相同轨迹试验评估）：

- `F_h_rms [N]`，`F_h_peak [N]`，`W_h_plus=integral(max(F_h*v,0),dt) [J]`。
- `completion_time [s]`、终点位置误差、行程超调、换向后最大反向过冲。
- 同一任务相对 C0/C1 的 RMS 手力改善比 `1-F_rms_new/F_rms_baseline`；单独输出，不能拿不同时间/不同轨迹的测试混算。

**手感与安全**：

- 加速度峰值、加速度 RMS、**带限 jerk**（不要对高频 IMU 噪声直接差分算 jerk）、启停瞬间冲击。
- 松手后的额外位移 `x(t_stop)-x(t_release)`、停稳时间、方向反转次数。
- 静止无推力下 10s 位移和最大速度；振荡检测（持续速度/力波动）。
- `|F_cmd|`、`|F_m|`、转矩峰值/持续时间、饱和占比、力变化率。
- 电机正机械功 `W_m_plus=integral(max(F_m*v,0),dt)`；**如无母线电流模型，不输出伪造的真实电耗/发热量**。
- 控制器状态占比、REST/START/MOVE/STOP 切换次数、异常/通信掉帧归零次数。

**全部指标给出平均、P95、最差值**；参数排名必须先剔除安全不合格配置。

## 10. 质量门槛与最终结论要求

**硬性检查**：

1. 关闭传感器误差、延迟、限幅、摩擦，取 `D=0`、`m=const`，C2 应符合理论等效惯量与阻尼。数值误差目标可先设 `RMSE_v` 相对于参考峰值速度不超过 2%，需说明积分步长和过渡段影响。
2. 正向/反向镜像输入（对称摩擦模型）应得到镜像运动，不能出现方向符号错误。
3. `F_h=0, x=v=0` 的站立试验不得产生持续自走；IMU 加偏置/刷头振动下要独立测。
4. 执行器饱和、通信丢失、失能必须实际生效；控制器不能绕过力/转矩限制。
5. 不同随机种子有统计变化，相同随机种子要结果可重现。
6. 控制代码不可引用 `plant.F_h_true / plant.D_true / plant.v_true / plant.a_true`；只有测试评估器可以访问真值（`oracle` 对照明确豁免并隔离）。

**工程期望（待实机标定确认，非既定验收指标）**：

- 在相同行程的人机耦合试验中，尽量降低相对于 C1 的 RMS/峰值手力，不明显延长完成时间。
- 松手后在预先定义的工况内平稳停止；可将 `|v|<0.03 m/s` 和停稳时长 `1–1.5s` 用作首轮观察标尺，实际阈值应以整机体验与地面工况确认。
- 不能为了让手力指标降低，牺牲静止不自走、反向可控、扭矩限制和异常安全。

**最终技术报告必须回答**：

1. 增加速度反馈 `-B_d*v_hat` 是否比现有 `i_base+k*a` 更稳、更容易停下来？代价是什么？
2. 有/无加速度反馈、是否加入摩擦补偿，三者各自能改善什么、会带来什么风险？
3. `K_a/m` 可工作的最大稳健区间是什么？敏感因素是质量误差、IMU 噪声、执行延迟还是轮速误差？
4. `B_d` 增大后为何可能更稳定，却变得「拖」？建议在哪个区间选择折中值？
5. 滚刷变化或干湿切换时，`alpha_D=1` 是否出现过补偿/主动窜动？更保守的最佳区间是什么？
6. 哪 3–5 组参数最值得上真实样机？各自工况边界和失效情形是什么？
7. 为将仿真落地到实机，**还需测量**哪些关键量（质量、半径、真实摩擦、Kt 或 F/i 映射、执行延迟、编码器滑移、UART 实测速率等）？

## 11. 实施注意事项（严禁偷换问题）

- **核心是单侧半车助力控制，不是电机自身的 PMSM 电磁建模**；先用电机力作为执行器，再映射到扭矩/电流。
- **阻抗控制优先**：`[a_hat,v_hat] -> F_cmd`；导纳方案使用 `F_h_hat -> v_ref -> F_cmd`，是可选对照，不得混成同一种控制器。
- 速度不能无条件当作从 IMU 积分得到的「干净真值」，必须建漂移/融合和噪声。
- 在只有 `a/v/i` 的情况下，`F_h` 与未知 `D` **不可同时唯一识别**；不可把未知刷头负载当成已知扰动进行完美抵消。
- 摩擦力可变号，且静止/反向/松手是重点；不能只做正向恒定速度运行。
- 需要客观比较**固定人力运动响应**和**固定运动任务的人力消耗**，这两个结果不是一回事。
- 所有数据来源分别标注：`SPEC`（厂家规格）、`USER_MODEL`（前期模型约定）、`ASSUMED`（示例值）、`MEASURED`（未来实测）；严禁将 `ASSUMED` 参数写成已测量事实。

**Herens 的执行目标**：先搭建严格的单侧被控对象和可用测量链路，完成 C0/C1/C2/C3 的定量比较；用图和指标证明哪种参数最稳、最省力、最符合期望的可调等效惯量/阻尼，而不是先验宣布「阻抗控制一定更好」。
